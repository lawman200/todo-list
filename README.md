# To-Do List

A command-line task manager written in Python for creating and managing an in-memory to-do list.

## Features

- Add new tasks
- View all tasks
- Edit existing tasks
- Mark tasks as completed or incomplete
- Delete individual tasks
- Delete completed tasks
- Delete all tasks with confirmation

## Requirements

- Python 3.10 or later

## Usage

A modern HTML, CSS, and vanilla JavaScript interface is included in this repo.

Run the app with the branded launcher:

```bash
cd /home/l2euser/Documents/todo_list
./start-todo-flow.sh
```

Then open <http://localhost:8080> in your browser.
